# KOReader 字数统计插件 v1.0
---
一个 KOReader 插件：统计当前书籍的总字数、实际已读字数和平均阅读速度，并把跨书籍的阅读量按日 / 周 / 月 / 年聚合成一个统计浮窗。

## 功能

---

### 字数统计

- **计数单位**：汉字 / 假名 / 谚文每个字符算 1 个单位；西文按空白分词，每个词算 1 个单位。
- **跨页不断词**：一个单词被分在两页上不会被算成两个。
- **精确口径**：整本书一次性取文本，避开 crengine 页边界吸附导致的重复 / 漏计。逐页拼接的误差会随页数线性累积（实测约 +2.3%），本插件默认不走那条路。
- **自动回落**：整书取文本失败时自动退回逐页路径，功能不退化。

### 阅读速度

- 逐页计时：停留时间短于阈值的翻页忽略，单页累计时间封顶，避免长时间离开被计入。
- 输出「字 / 分钟」。

### 阅读统计浮窗

- 以**居中浮窗**形式打开，不跳转整页，背后仍能看到书；点浮窗外空白或按实体返回键关闭。
- 两个视图：**总览** / **阅读趋势**。
- 四个周期：**日 / 周 / 月 / 年**，可切换年份。
- 统计指标：阅读字数、阅读时间、阅读速度、阅读天数、读完书籍、单日阅读最久、日均阅读时长。
- 卡片网格按屏宽自动排 **1 ~ 3 列**。
- 趋势图三种样式：**连线 / 点线 / 方框**。

### 批量统计

- 在文件管理器里**多选**文件，或用 **Bookshelf** 插件批量选中，一次性统计多本。
- 进度条显示「第 X / N 本」。
- 逐本给出跳过原因：有缓存 / 文件过大 / 无文本层 / 无法分页 / 无法打开 / 等待超时。

### 缓存

- 用**文件指纹**（修改时间 + 文件大小）判断缓存是否还有效。
- 命中缓存直接出结果，**不启动扫描**。
- 缓存上限 500 条，超出后按写入时间淘汰最旧的。

### Bookshelf 集成

启用后可以在 Bookshelf 的模板里使用三个占位符：

| 占位符                 | 含义   |
| ------------------- | ---- |
| `{word_count}`      | 全书字数 |
| `{word_count_read}` | 已读字数 |
| `{word_speed}`      | 阅读速度 |

## 安装

1. 从 [Releases](../../releases/latest) 下载 `wordcount-v1.0.koplugin.zip`
2. 解压，得到 `wordcount.koplugin` 文件夹
3. 把整个文件夹放进 KOReader 的 `koreader/plugins/` 目录
4. 重启 KOReader

目录结构应该是这样：

```
koreader/
└── plugins/
    └── wordcount.koplugin/
        ├── main.lua
        ├── page_text.lua
        ├── word_count.lua
        ├── reading_stats.lua
        ├── global_stats.lua
        ├── statistics_page.lua
        ├── bookshelf_integration.lua
        └── _meta.lua
```

> 插件**只在重启后生效**。装完如果菜单里没出现，先确认目录名是 `wordcount.koplugin`（不能改），以及里面是 `.lua` 文件而不是又套了一层文件夹。

## 使用

### 菜单入口

**文件管理器 → 顶部菜单 → 「设置」标签 → 字数与阅读速度**

菜单最上面一行会显示当前版本号，点一下弹通知——装完新包可以靠它确认装的是哪一版。

### 快速统计

- **当前正在读的书**：打开插件菜单 → 「统计全书字数」
- **文件管理器里的某本书**：长按该文件 → 「统计本书字数」
- **多本**：多选文件 → 「统计选中字数」
- **看已有结果**：菜单 → 「查看字数与阅读速度」

### 阅读统计页面

菜单 → 「打开阅读统计页面」。

## 设置项

| 设置           | 说明                             | 默认                        |
| ------------ | ------------------------------ | ------------------------- |
| **单位显示**     | 完整数字（带千分位）/ 万 / 亿（自动）/ k / 千   | 自动（万/亿）                   |
| **统计模式**     | 完整扫描（精确）/ 抽页估算（只扫前 100 页，标「约」） | 完整扫描                      |
| **大书处理**     | 超限直接取消 / 超限改用抽样估算              | 超限直接取消                    |
| **降级阈值**     | 触发降级的页数上限 / 文件大小上限             | 20000 页；epub 20MB、其他 32MB |
| **多选本数阈值**   | 批量选中多少本起自动改用抽页估算               | 5 本                       |
| **取消全书字数统计** | 中止正在进行的扫描                      | —                         |

> 统计模式的选择会被记住。改了模式之后，**已经缓存的结果仍按原来的模式**，想重算就在书或文件上重新点一次统计。

## 性能与耗电

| 场景            | 耗时                         |
| ------------- | -------------------------- |
| 命中缓存          | ≈ 0（不扫描）                   |
| 抽页估算（前 100 页） | ≈ 1 秒                      |
| 完整扫描（1000 页）  | ≈ 9.4 秒                    |
| 批量 50 本完整扫描   | 3 ~ 8 分钟（会持续跑满 CPU，机身明显发烫） |

针对老设备做的取舍：

- 扫描分批进行，每 10 个批次主动休息 1.2 秒，给 SoC 降频和进入 idle 的机会。
- 进度刷新有最小间隔节流，且只重绘**最小的屏幕区域**，避免 e-ink 整屏闪烁。
- 批量统计选中 **5 本以上**时自动临时改用抽页估算（只对本次生效，**不会**改掉你的全局设置），并在开始时提示。

## 大书保护

超大书籍最容易把 512MB 的设备打爆内存，表现是「卡死然后自动重启」。插件设了多道闸门：

| 闸门      | 阈值                  | 行为                       |
| ------- | ------------------- | ------------------------ |
| 整书一次取文本 | 5000 页              | 超过则改走逐页路径，避免一次性读入全本文本    |
| 逐页全扫    | 20000 页             | 超过则不逐页扫描                 |
| 逐页明细记录  | 50000 页             | 超过则不再记录每页字数（**总字数仍然精确**） |
| 文件大小    | epub 20MB / 其他 32MB | 超过则跳过整本排版，防止内存耗尽         |

**默认策略是「超限直接拒绝统计」**——宁可这本书统计不了，也绝不让设备重启（重启会打断你正在读的书，代价更大）。如果确实想统计，可以在菜单里把「大书处理」改成「超限改用抽样估算」。

## 兼容性

- **精确支持**：EPUB、HTML、FB2、TXT（走 CRE 引擎的 XPointer 接口）
- **回退支持**：其他提供 `getPageText` 的文档类型
- **不支持**：没有文本层的扫描版 PDF —— 会提示「无文本层」并跳过

---

## 已知限制

- 扫描版（图片型）PDF 无法统计，需要先做 OCR。
- 抽页估算模式下数字前面会标「约」，页间分配是估算值；**全书总字数在完整扫描下是精确的**。
- 已读字数依赖逐页明细，超过 50000 页的书只有总字数精确。
