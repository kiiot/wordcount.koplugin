## 安装
---
1. 下载下方的 `wordcount-v1.0.koplugin.zip`
2. 解压后，把 `wordcount.koplugin` 文件夹放到 `koreader/plugins/` 下
3. 重启 KOReader 生效

##实现内容
---
### 1. 字数统计（核心）
计数单位是「阅读单位」：汉字/假名/谚文每个字符算 1，西文按空白分词算 1。
自己手写了 UTF-8 解码器（LuaJIT 不保证有 utf8 库），坏字节当分隔符处理，损坏文本不抛异常。
跨页的单词不会被算两次（in_word 状态跨页传递）。
精确路径：整书一次性取文本（首页 XPointer → 末尾）。因为 crengine 的 getPageXPointer 会把页边界吸附到文本节点上，逐页拼接会重复/漏计，实测每页多吸一个节点 ≈ 膨胀 2.3%，误差随页数线性累积。整书取失败会自动回退逐页路径。
### 2. 阅读速度
逐页计时，停留短于阈值忽略、单页累计封顶，输出「字/分钟」。页字数优先用真实提取值，早期垫的估算值会在你真读到那页时被覆盖「自愈」。
### 3. 阅读统计浮窗
居中浮窗而不是整页跳转，点外面/返回键关闭，背后能看到书；标题栏跟着滚动一起走。
两个视图：总览 / 阅读趋势；周期 日 / 周 / 月 / 年，可切年份。
指标：阅读字数、阅读时间、阅读速度、阅读天数、读完书籍、单日阅读最久、日均阅读时长。
卡片网格 1~3 列自适应；趋势图三种样式（连线 / 点线 / 方框）。
视觉上专门调过：字号加大、无灰色字、无滚动条，导航「未选中白底黑框、选中黑底反白」。
### 4. 大书防护（防设备重启）
拆开 loadDocument / renderDocument——页数已知就跳过 render（整本 render 会额外吃 ~130MB，几万页的书直接 OOM 重启）。
文件大小闸门：epub 12MB / 其他 24MB；整书取文本另有页数闸门。
超限策略二选一：直接取消（默认，最安全）​ 或 自动降级为抽样估算；两个阈值都能手填。
### 5. 省电
默认抽页模式：只扫前 100 页按比例外推，数字标「约」；精确模式随时可切回，选择永久记住。
批量 ≥5 本自动临时降级（只存在 job 表里，不写全局设置）。
扫描 tick 0.25s、进度刷新 1.5s、最小重绘间隔 0.5s，每 10 个 tick 休息 1.2 秒。
每次只刷最小 region，不整屏刷——e-ink 上避免糊屏。
实测：命中缓存 ≈ 0；抽页 100 页 ≈ 1 秒；完整扫描 1000 页 ≈ 9.4 秒。
### 6. 批量与缓存
文件管理器多选 / Bookshelf 批量，进度条显示「第 X / N 本」。
跳过原因分六类：有缓存 / 文件过大 / 无文本层 / 无法分页 / 无法打开 / 等待超时。
缓存用文件指纹（mtime + size）判有效性，上限 500 条按时间淘汰；命中缓存直接出结果，根本不启动扫描。
### 7. 显示与集成
单位显示：完整数字（带千分位）/ 万 / k / 千 / 自动。
Bookshelf 插件占位符：把 word_count、word_count_read、word_speed 塞进 Bookshelf 模板。
