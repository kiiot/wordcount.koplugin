## wordcount.koplugin → 构建 58（Bookshelf 6.x 适配 + 上限交给用户）

用户报两件事：
1. 「不适配最新版 bookshelf 了，多选的选项里没有统计字数的选项」
2. 「那个页数限制，不需要你放限制，我自己输入限制数字」

### 根因（1）
- 用户设备已升到 **Bookshelf 6.4.2**（上游 github.com/AndyHazz/bookshelf.koplugin，
  release v6.4.2，2026-11-09）。仓库里的本地副本 `E:/kindle越狱/官方插件/bookshelf.koplugin`
  仍是 3.10.9（_meta version 3.10.9）。
- 6.x 的 `BulkActions.show` **不再建 ButtonDialog**，改交给 `lib/bookshelf_page_dialog`
  （page 模型：`{page=function() return {strip, blocks} end, title, footer, on_close}`；
  块类型 heading/chips/segmented/row/slider/stepper/option/slot，由 `lib/bookshelf_editor_page` 渲染）。
  ⇒ 旧的两条腿（拦 `ButtonDialog.new` / 往栈顶 widget 的 `.buttons` 补行）全部静默失效。
- 修法：包 `BulkActions.show` 收到的 `opts.page` 函数，在返回的模型里追加
  `{type="heading",text="字数统计"}` + `{type="chips",items={{text="统计选中字数",callback=...}}}`。
  幂等标记 `_wordcount_bulk_block`；关框优先 `dialog._dismiss()`；
  点按动作统一抽成 `startBulkCount()`（新旧三条腿共用）。
  腿 2（`_openBulkMenu`）也补了 6.x 分支（替换栈顶 `page` 再 refresh），兜底 require 失败的情况。
- 6.4.2 仍不变的契约：`Selection:paths()/exitMode()/count()`、
  `BookshelfWidget:_fileDialogPluginRows`（单本菜单仍有效）、
  `lib/bookshelf_tokens` 的 expanders/CATALOGUE/expand（三个占位符不受影响）。

### 改动（2）
- `DEFAULT_DOWNGRADE_PAGES` 20000 → **0 = 不限制**；`downgradePages()` 认 0；
  `downgradeBytes()` 未设/0 → **math.huge**（不再按格式默认 20/32MB）。
- 判据必须先确认限制存在（`limit > 0` / `~= math.huge`），否则 0 会让每本书都超限。
- 菜单：父项「页数 / 大小上限：不限 / 不限」，输入框说明首行「填 0 = 不限制」，
  第三颗按钮「默认」→**「不限」**；拒绝文案改为「超过了你设的上限」。
- 安全网改造：整书一次取文本的闸门改成**无条件硬闸**（页数>5000 或 体积>24MB 就走逐页），
  否则「默认不限制 + 禁止降级」会让 219MB/9 万页的书走整书路径必 OOM；
  新增 30000 页且无上限时的**三选确认框**（完整/抽样/取消），`_force_sample_once` 只影响本次。
- `_meta.build` 57 → **58**；README 增加 Bookshelf 版本兼容表 + 新的上限说明。

## v1.2：清理代码 + 新增在线更新

用户要求：「把代码里面无关的东西删掉，以及里面可以加推送更新的操作吗，就像 bookshelf 一样，把版本更新为 1.2」。
清理力度选「删死代码 + 精简注释」；更新方式选「只在菜单里手动检查」。

### 清理结果
- 总量 **16417 → 9201 行**（含新增 updater 316 行）。
- `_meta.lua` 3871 → **7 行**（原来 99% 是注释，只剩 fullname/description/version）。
- `main.lua` 5236 → 3706 行；`statistics_page.lua` 5672 → 3872 行。
- 删掉的死代码：`wrapBulkActionsShow` 里旧的 `ButtonDialog.new` 拦截分支、
  `installBulkMenuButtonPatch` 里的 ButtonDialog 兜底段、未使用的
  `batchThresholdDisabled()` / `fmtDuration()` / `BATCH_SAMPLE_THRESHOLD` 常量、
  开发预览文件 `kpw4_daily_preview.html`。
- 去掉 `build` 概念（菜单只显示 `版本：1.2`）。
- 注释压缩用脚本 `E:/agit/wordcount-build/compress_comments.py`：
  **带等价性自检** —— 剥离注释 + 折叠空白后新旧代码必须完全一致，否则拒绝写盘。
  规则：英文块原样保留；中文块留首行（断句就补第二行，最多 5 行）；
  块里有 ⚠/⇒ 保那一行；「用户抱怨…」式开发日记整块丢弃。

### 在线更新（updater.lua）
- 手动检查：菜单新增「检查更新」→ `Updater.check()`。
- 流程：`NetworkMgr:runWhenOnline` → GET `api.github.com/repos/kiiot/wordcount.koplugin/releases/latest`
  → 版本比较（parseVersion 逐段比，1.10 > 1.9）→ TextViewer 显示更新说明 +
  「更新并重启」/「关闭」→ 下载 zip 到 `getSettingsDir()/wordcount_update.zip`
  → `ffi/archiver` 解压并剥掉顶层目录、覆盖**自身目录**（`debug.getinfo` 定位，
  失败回落 `getDataDir()/plugins/wordcount.koplugin`）→ ConfirmBox 提示重启。
- 网络栈：socket.http + ltn12 为主，`curl` 兜底（桌面/安卓）。
- `main.lua` 用 pcall 加载 updater，失败时菜单项给提示而不拖垮插件。
